# 注意

由于时代发展太快，Mod制作日新月异，而我基本上没做过Mod，经过深思熟虑后，决定从即日起，不再维护SSMT的Mod制作功能，包括TheHerta4的Mod制作功能也会停止维护。

后续已赞助LTS技术支持的用户仅维护原神Mod防报错和Mod逆向的更新。

以后兄弟们制作Mod就用gui_collect + XXMI-Tools吧，天下无不散的宴席，至少Mod制作这块儿俺已经无力维护。

并非跑路，有非Mod制作的问题可以继续私信我，此外工具正在经历转型重构中，敬请期待全新的Mod逆向工具以及Mod启动器兼加载器。
