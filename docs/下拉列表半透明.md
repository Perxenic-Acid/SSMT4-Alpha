# 下拉列表半透明玻璃风格

> 源自贴图标记页面（`MarkTextureFull.vue`）的下拉列表样式 — Element Plus `el-select` / `el-dropdown` 半透明毛玻璃

## 样式效果

- 选择器/输入框背景：半透明白 `rgba(255,255,255,0.06)`
- 下拉弹窗：深色半透明底 + 强模糊 `blur(12px)`
- 弹出菜单项 hover：浅白高亮

## 核心 CSS

### 选择器/输入框 wrapper（scoped 内）

```css
:deep(.el-input__wrapper),
:deep(.el-select__wrapper) {
	background: rgba(255, 255, 255, 0.06);
}
```

> **注意**：Vue 3 scoped 中根级 `:deep()` 只在目标元素是组件根元素时生效。如果不起作用，加父容器前缀：
> ```css
> .page-container :deep(.el-input__wrapper) { ... }
> ```

### 下拉弹窗 / 菜单（global style，弹窗在 body 下）

```css
.el-popper.is-pure .el-select-dropdown,
.el-popper.is-pure .el-dropdown-menu {
	background: rgba(20, 22, 30, 0.92) !important;
	backdrop-filter: blur(12px) !important;
	-webkit-backdrop-filter: blur(12px) !important;
	border: 1px solid rgba(255, 255, 255, 0.10) !important;
}
.el-popper.is-pure .el-select-dropdown__item.hover,
.el-popper.is-pure .el-select-dropdown__item:hover {
	background: rgba(255, 255, 255, 0.06);
}
.el-popper.is-pure .el-dropdown-menu__item:not(.is-disabled):hover {
	background: rgba(255, 255, 255, 0.06);
	color: #409eff;
}
```

> 必须放在非 scoped 的 `<style>` 块中，因为弹窗被 teleport 到 `body` 下，不在组件 DOM 树内。

## 使用方式

1. 在组件的 `<style scoped>` 中添加 input/select wrapper 样式
2. 另开一个 `<style>`（无 scoped）块添加弹窗样式
3. 如果页面内有多个 `el-select` / `el-dropdown`，所有弹窗会自动应用
